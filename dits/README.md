# DiTs – Lerntrainer Mobil

Lern-App für die Umschulung **Fachinformatiker Systemintegration** (AP1).
Läuft als installierbare Web-App (PWA) – auch offline.

- Quiz, Blitzrunde (wischen), Karteikarten, Zuordnen
- Rechentrainer (Subnetting im IHK-Stil, Kalkulation, SLA, RAID, PoE, Speichergrößen …)
- Prüfungssimulation mit Kundenszenarien und IHK-Note
- Hell- und Dunkelmodus

Der Lernfortschritt wird nur im Browser des Geräts gespeichert.
